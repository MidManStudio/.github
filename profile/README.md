### About MidManStudio

MidManStudio is an indie game development studio founded by **Mid** (*AbdulHamid Muhammad Suleiman*). 

We prioritize building our technology stack in-house from first principles rather than relying solely on off-the-shelf packages. While game development is our core focus, our engineering spans across the entire digital spectrum—if it's digital, we build it.

### What We Build

* **Game Development:** Tailored 2D & 3D game experiences, rendering pipelines, and game logic.
* **Systems Programming:** Low-level engines, custom file specs, protocols, and high-performance tools.
* **Web & Applications:** Desktop software, mobile applications, and web platforms.
* **Experimental Engineering:** Custom infrastructure, language tools, and unhinged technical prototypes.
